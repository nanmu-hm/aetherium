# Narrative Emphasis and Convergence

These detectors deliberately separate:

- historical magnitude: how much state changed in one event;
- narrative importance: why the event may matter to a developing story;
- thread convergence: where previously separate causal threads begin to interact;
- foreshadowing candidates: later events that reuse already-existing causal keys.

Foreshadowing is stored as a candidate link discovered after the fact. The engine never claims that an earlier event was intentionally planted by an author unless that intent is represented elsewhere.
