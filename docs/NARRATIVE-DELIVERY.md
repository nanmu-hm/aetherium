# Narrative Resource and Completion Contract

The narrative layer now separates structure from presentation priority:

World history -> importance -> treatment -> interleaving -> callback timing -> completion assessment.

Resource allocation chooses summarize, dramatize, slow_down, or interiority. It is a presentation recommendation, not an instruction to the simulation.

Completion requires evidence. Unresolved questions keep an arc open; an observed payoff plus resolved threads can mark it complete.

Multi-arc interleaving alternates independent arcs when possible instead of forcing one plot line to monopolize the reader.
