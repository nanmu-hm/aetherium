# Aetherium World Constitution

## Purpose

This document defines the non-negotiable principles of the Aetherium simulation. It is a design contract, not a plot outline.

## 1. State is authoritative
Persistent world state is the source of truth. Agents must not silently invent state and treat it as established fact.

## 2. Characters have agency
A character acts from goals, values, personality, relationships, knowledge, constraints, and current emotion. Plot convenience is not a valid motive by itself.

## 3. Consequences persist
Actions produce durable consequences. Consequences can alter resources, knowledge, relationships, reputation, organizations, locations, injuries, memories, and future choices.

## 4. Knowledge is local
Characters may act only on information available to them, unless a defined mechanism gives them new information. The system must distinguish facts, beliefs, rumors, and false beliefs.

## 5. Time and space are causal
Characters cannot teleport. Movement consumes time. Simultaneous events must respect location and availability. Every event has a timestamp and relevant location or scope.

## 6. The world continues without the protagonist
Non-player characters and organizations retain goals and may act while the primary protagonist is elsewhere or inactive.

## 7. Relationships are dynamic state
Relationships are not static labels. Trust, affection, loyalty, fear, rivalry, debt, resentment, and cooperation can change through events.

## 8. Plot remains open
The system defines world rules, character identity, and thematic constraints more strongly than it defines future plot. Future events should emerge from the simulation whenever possible.

## 9. Canon has provenance
Every important fact should have provenance: source canon, user decision, derived state, simulation event, or proposal. Agents must not silently upgrade a proposal into canon.

## 10. User intervention is versioned
When the user changes the world, the change becomes an explicit state transition. The system should support alternate branches rather than silently destroying history.

## 11. Narrative is downstream
The prose layer must not retroactively change the simulated world merely to make a scene better. If prose requires a contradiction, the contradiction must be surfaced for resolution.

## 12. Emergence is observable
Autonomous evolution must leave an inspectable event trail so the user can understand why a character acted, why an event happened, and how the current world state emerged.
