# Literary Expression Foundation

Aetherium now inserts a deterministic expression-control layer between narrative structure and prose generation.

World Truth -> Narrative Discovery -> Story Structure -> Expression Plan -> LLM Prose

The expression layer owns global literary identity, character voice profiles, scene-level viewpoint and narrative distance, dialogue/emotional/sensory/exposition controls, subtext and omission intensity, recurring motif observations, and provenance-oriented pre-canon checks.

It does not write outcomes into the world. It describes how already-observed history may be expressed.

Motifs are discovered from repeated existing event language. They are not planted retroactively.
