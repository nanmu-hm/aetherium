# Narrative Intelligence Contracts

The narrative layer derives four kinds of structure from authoritative history:

1. Causal threads connect nearby events that share observed causal state keys such as participants or relationship consequences.
2. Character arcs detect persistent changes in identity, goals, emotions, and relationships.
3. Information gaps compare character-local knowledge; the global event log is never treated as universal knowledge.
4. Revelation candidates identify a grounded source/target pair where an existing relationship could transmit a fact.

None of these detectors mutate WorldState.

A revelation candidate is an opportunity, not a scripted revelation.
