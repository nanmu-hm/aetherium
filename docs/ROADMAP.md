## Guiding rule

Do not add UI complexity faster than the underlying simulation and narrative models become trustworthy.

The first meaningful milestone is not "AI wrote a chapter".

It is:

> A deterministic world can evolve for a long time, characters make causally consistent choices, consequences persist, and the system can discover a non-trivial story thread from that history.
