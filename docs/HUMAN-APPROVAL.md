# Human-in-the-Loop Approval and Draft/Canon Separation

Aetherium separates **world canon**, **narrative draft**, and **narrative canon**.

## Three boundaries

1. **World State / simulation canon**
   - authoritative facts about characters, relationships, events, memory, locations, and other simulation state;
   - changed only through the existing intervention/state-management boundary;
   - Writer and narrative agents cannot write here.

2. **Narrative Draft**
   - prose generated by Writer or revised by a human;
   - versioned and non-authoritative;
   - may be rejected or superseded;
   - carries immutable provenance: source event IDs, participant IDs, viewpoint, branch, and tick.

3. **Narrative Canon**
   - a human-approved version of a narrative draft;
   - stored in an append-only narrative canon ledger;
   - approval records the exact prose and its provenance;
   - approval does not mutate World State.

## Workflow

```
Simulation
    |
    v
NarrativeObserver
    |
    v
WriterAgent
    |
    v
NARRATIVE_EDIT proposal
    |
    v
Narrative Draft v1
    |
    +----> Human edits ----> Draft v2
    |                           |
    |                           v
    +----> Reject           Human Approval
                                |
                                v
                         Narrative Canon
```

When a human revises a draft, only presentation fields such as prose and title change. Source event IDs, participants, viewpoint, branch, and tick are preserved from the originating draft.

This is deliberate: changing the prose is not the same thing as changing history.

## Authority rule

A narrative draft may describe or emphasize existing history, but it cannot itself create a new world fact. A request to change an actual character, event, relationship, or world rule must continue through the intervention system and its explicit approval/fork rules.

## Future model-backed Writer

A model-backed Writer may replace deterministic prose generation later. The draft/approval boundary remains unchanged: model output is still Draft until a human explicitly approves it.
