# Aetherium Vision

> chatgpt+胡明的小世界

Aetherium is an experimental world-and-narrative engine for creating fictional worlds that can evolve through autonomous agents and eventually produce coherent stories and novels.

## Core idea

Aetherium does not begin with prose. It begins with a world.

The intended causal loop is:

World State → Character Desire → Decision → Action → Event → Consequence → World State Change → Character Change → New Desire

A story should be able to emerge from this loop rather than being completely pre-scripted.

## Four operating modes

1. **Collaborative Mode** — the user participates directly in story decisions.
2. **Director Mode** — agents choose among possible narrative developments.
3. **Character Simulation Mode** — characters are tested under changing circumstances to validate behavioral consistency.
4. **World Evolution Mode** — the user provides a world seed and rules, then the world runs with minimal intervention.

## Design principles

- Character core values and behavioral patterns are stronger constraints than plot convenience.
- World rules should be stable; plot routes should remain comparatively open.
- Consequences must persist. Events should change state, memory, knowledge, relationships, organizations, and future choices.
- Agents should have distinct responsibilities instead of becoming one undifferentiated super-agent.
- The system must preserve causal continuity and spatial/temporal consistency.
- Narrative extraction is separate from world simulation: the world may generate history that is not itself a novel.
- The system should support user intervention at any layer without destroying the underlying world state.

## Long-term architecture

World Simulation → Emergent History → Narrative Emergence → Story Arcs → Novelization

Aetherium is therefore both a creative tool and an experiment in autonomous fictional-world evolution.
